* Que es ? 
 # Intelligence Quotient (Cociente Intelectual)
 # Un servicio que conecta con  expertos certificados de AWS 
 # Permite contratar ayuda para proyectos de AWS 
 # Es un Marketplace de consultores  AWS oficiales

* Para que sirve?
 # Ayuda a migrar a AWS
 # Optimiza arquitectura
 # Configurar Seguridad
 # Resolver problemas técnicos
 # Implementar buenas prácticas

* Ejemplos reales 
 # Una empresa necesita migrar su infraestructura on-premise
 # Necesitas ayuda para configurar Kubernetes en AWS
 # Problemas complejos con networking o seguridad
 # Optimización de costos

* Como funciona
 # Publicas una solicitud describiendo tu necesidad
 # Expertos certificados respondes con propuestas
 # Acuerdas precio y alcance
 # El pago se realiza a través de AWS
 # AWS verifica que los expertos tengan certificaciones ACtivas

* Caracteristicas importantes
 # Solo expertos certificados en AWS
 # Pago seguro a través de AWS
 # Ideal para proyectos específicos
 # No es un servicio técnico automático, es humano

* Diferencia entre otros servicios
 # AWS Support → Soporte técnico oficial de AWS
 # AWS IQ → Consultores externos certificados
 # AWS Professional Services → Servicios empresariales oficiales de AWS
