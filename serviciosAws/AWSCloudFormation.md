# AWS CloudFormation

# servicio de infraestructura como codigo que permite crear y administrar recursos de AWS mediante plantillas
# ¿Tu equipo pierde tiempo configurando manualmente la infraestructura?

# CloudFormation automatiza y replica entornos completos mediante plantillas, reduciendo errores y acelerando despliegues.

## Función Principal
Provisión de infraestructura como código mediante plantillas YAML o JSON

## Características Clave
- Infraestructura como código (IaC)
- Manejo de dependencias
- Cambios controlados con change sets

## Casos de Uso Típicos en el Examen
- Despliegue automatizado de entornos consistentes
- Plantillas reutilizables en múltiples regiones

## Integraciones Comunes
- IAM
- EC2
- S3
- Lambda
- SNS

## Palabras Clave que Suelen Aparecer en Preguntas
- IaC
- Plantilla
- Change set
- Despliegue reproducible

## Errores Comunes que el Examen Intenta Evaluar
- Confundir con Terraform
- No usar parámetros o recursos anidados correctamente
