* Que es?
 # Es un servicio pensado para crear servidores virtuales de forma simple, rápida y con precio fijo mensual
 # Basicamente una VPS (Virtual Private Server) fácil de usar, ideal para proyectos pequeños o medianos

* Para que se usa?
 # Hosting de páginas web (WordPress,Node.js,ETC)
 # APis pequeñas
 # Servidores en desarrollo
 # Bots
 # Aplicaciones simples
 # Bases de dato pequeñas
 # Servidores de juegos livianos

* Que incluye?
 # Cuando crear una instancia en Lihtsail obtienes
  - Máquina virtual(CPU + RAM)
  - SSD
  - IP pública fija
  - Firewall simple
  - Monitoreo básico
  - Precio mensual fijo 

* Ejemplo 5 USD/mes → 1vCPU, 512 MB RAM, 20 GB SSD  
* 10 USD/ mes → más ram y almacenamiento
 # (Sabes exactamente cuánto pagarás cada mes)

* En qué se diferencia de EC2?
 # Lightsail	            EC2
 # Simple	                Avanzado
 # Precio fijo mensual	    Pago por uso
 # Configuración básica	    Totalmente personalizable
 # Ideal para principiantes	Ideal para arquitecturas complejas
 
# Si quieres algo rápido y sin complicarte → Lightsail
# Si quieres arquitectura empresarial y control total → EC2

 * Cuando usar AWS Lightsail?
  # Proyecto pequeño
  # Necesitas simplicidad
  # No quieres conviguarar VPC manualmente
  # Quieres precio fijo mensual
  # Startup o MVP

  # Arquitecturas complejas
  # Microservicios avanzados
  # Control granular de red
  # Auto Scaling avanzado
