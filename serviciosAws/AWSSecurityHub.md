* Que es?
 # Es un servicio que centraliza y consolida hallazgos de seguridad de múltiples servicios de AWS y herrmaientas de terceros en un solo panel
 # Es el centro de control de seguridad de tu cuenta AWS

* Que hace ? 
 # Recoge hallazgos de servicios como:
  - Amazon GuardDuty
  - Amazon Inspector
  - AWS IAM Access Analyzer
  - AWS Firewall Manager
 # Los normaliza en un formato estándar
 # Evalúa cumplimiento con estandáres de seguridad
 # Muestra todo en un dashboard centralizado
