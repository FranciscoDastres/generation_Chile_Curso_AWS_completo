* Que es?
 # Amazon Lex es un servicio para crear Chatbots y asistences conversacionales
 # Usan inteligencia Artificial (IA)
 # Permite interacción por voz o texto
 # Es la misma tecnología que usa Amazon Alexa
 # Sirve para crear bots que entienden lenguaje natural

* Para que sirve
 # Para construir 
  - Chatbots para atención al cliente
  - Bots en aplicaciones web o móviles 
  - Asistentes virtuales
  - Sistemas de autoservicio
  - Integración con call centers

* Ejemplos reales:
 # Bot que responde preguntas frecuentes
 # Bot que agenda citas
 # Bot que consulta saldo bancario
 # IVR inteligente en un call center (Interactive Voice Response)

* Amazon Lex trabaja con 
 # Intents → Que quiere hacer el usuario
 # Utterances → Frases que puede decir el usuario
 # Slots → Datos que el bot necesita (fecha, nombre, etc)

* Ejemplo: 
# Usuario: "Quiero reservar una cita mañana"
# Intent: ReservarCita
# Slot: Fecha = mañana

# Luego puede integrase con AWS Lambda para ejecutar lógica

* Características importantes
 # Serverless
 # Reconocimiento de voz y texto
 # Integracion con Lambda
 # Se integra con Amazon Connect
 # Escalable automáticamente

* Diferencia con otros servicios
 # Amazon Lex → Crea el chatbot
 # Amazon Polly → Convierte texto a voz
 # Amazon Transcribe → Convierte voz a texto
 # Amazon Connect → Plataforma de call center

* Frase para memorizar
 # Lex = chatbot inteligente con IA
