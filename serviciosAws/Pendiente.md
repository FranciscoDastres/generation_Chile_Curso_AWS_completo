Pruebas unitarias
Preguntas y Respuestas (Ordenadas y Consolidadas):
Pregunta 1:
Descripción: Está diseñando una solución de dispositivos conectados usando AWS IoT Core y desea implementar un protocolo de comunicación ligero adecuado para escenarios IoT. ¿Qué protocolo de mensajería se usa comúnmente para la comunicación entre dispositivos y AWS IoT Core?
Respuesta Correcta: d. MQTT

Pregunta 2:
Descripción: ¿Cuál es el número correcto de tablas de enrutamiento admitidas por Amazon VPC?
Respuesta Correcta: a. 200

Pregunta 3:
Descripción: ¿Qué servicio AWS proporciona una solución de almacenamiento NFS compatible con POSIX, totalmente administrada y rentable? (Seleccione DOS)
Respuestas Correctas: c. AWS Elastic File System, a. Amazon FSx for Lustre

Pregunta 4:
Descripción: Mi organización necesita automatizar el proceso de compilación y despliegue de sus artefactos de código almacenados en repositorios de proyectos. ¿Qué servicio AWS ayudará a hacerlo?
Respuesta Correcta: b. Ambos A y B (CodeBuild y CodePipeline)

Pregunta 5:
Descripción: En una aplicación de soporte al cliente, se necesita un chatbot para ayudar a los usuarios a encontrar respuestas rápidas a preguntas frecuentes. ¿Qué servicio AWS es adecuado para construir este chatbot con capacidades de comprensión del lenguaje natural?
Respuesta Correcta: c. Amazon Lex

Pregunta 6:
Descripción: En un proyecto de desarrollo, un equipo necesita un servicio para automatizar la compilación y prueba de cambios de código en un entorno de integración continua (CI). ¿Qué servicio AWS es adecuado?
Respuesta Correcta: b. AWS CodeBuild

Pregunta 7:
Descripción: ¿Cuál de los siguientes describe con precisión un caso de uso típico en el que se puede utilizar el servicio AWS CodePipeline?
Respuesta Correcta: d. Compilar y desplegar un microservicio en EC2 o Lambda

Pregunta 8:
Descripción: Una startup de e-learning necesita ejecutar una aplicación durante la temporada de vacaciones (2 meses) en EC2. El tiempo de inactividad afectaría negativamente su reputación. ¿Qué opción es más rentable?
Respuesta Correcta: d. Reservada (Nota: "Reservada" corresponde a Instancias Reservadas)

Pregunta 9:
Descripción: Un cliente quiere acceder a 6 verificaciones de seguridad básicas (permisos S3, grupos de seguridad, IAM, MFA, snapshots públicos). ¿Qué planes de soporte ofrecen estas verificaciones al menor precio? (Seleccione DOS)
Respuestas Correctas: e. Developer Plan, a. Business Plan

Pregunta 10:
Descripción: ¿Qué principios de diseño de la nube de AWS pueden ayudar a aumentar la fiabilidad? (Seleccione DOS).
Respuestas Correctas: d. Recuperación automática de errores, e. Probar los procedimientos de recuperación

Pregunta 11:
Descripción: Una empresa quiere mejorar su postura de seguridad y auditoría limitando el acceso entrante a Amazon EC2. ¿Qué debería usar la empresa para acceder a las instancias de forma remota en lugar de abrir los puertos SSH entrantes y administrar las claves SSH?
Respuesta Correcta: c. AWS Systems Manager Session Manager

Descripción: ¿Qué beneficio de AWS permite a los usuarios implementar una infraestructura en la nube compuesta por múltiples regiones geográficas conectadas por una red de baja latencia, alto rendimiento y redundancia?
