* Que es?
 # es un servicio administrado de AWS que permite crear,entrenar y desplegar modelos de Machine Learning en la nube
 # Es la plataforma completa de ML en AWS

 * Para qué sirve?
  # Construir modelos de LM
  # Entrenar modelos con grandes volúmenes de datos
  # Desplegar modelos en producción
  # Crear prediccione en tiempo real o por lotes
  # Automatizar pipelines de ML

 * Que permite hacer?
  # Build
   - Jupyter Notebooks integrados
   - Sagemaker Studio
   - Integración con PYthon y frameworks (TensorFlo, PyTorch,etc)

  # Train 
   - Entrenamiento distribuido
   - Uso de GPU
   - Escalado automático
   - Hyperparameter tuning automático

  # Deploy
   - Endpoints en tiempo real
   - Batch inference ( es cuando un modelo de ML procesa grandes cantidades de datos de una sola vez)
   - Auto Scaling para modelos
