* Qué es ?
 # Servicio de AWS que convierte texto en voz realista
 # Transforma texto escrito en audio hablado

* Para que sirve?
 # Generar voz para aplicaciones
 # Crear asistentes virtuales
 # Sistemas IVR
 # Audiolibros
 # Accesibilidad (lectura de texto)

* Que tipos de voces ofrece?
 # Voces estándar
 # Voces Neuronales (NTTS) Más naturales y realistas
 # Soporte para múltiples idiomas 

* Qué permite hacer
 # Convertir texto a audio MP3 u otros formatos
 # Elegir idioma y voz
 # Ajustar velocidad y tono
 # Usar SSML(Speech Synthesis Markup Language)

* Cuando usar Amazon Polly?
 # Necesitas una app que hable
 # Crear IVR en callcenters
 # Generar narraciones automáticas
 # Accesibilidad para personas con discapacidad visual 

* Cuando no usarlo 
# si necesitas convertir voz a texto
 # en ese caso → Amazon Transcribe 

# Polly vs Transcribe
 # Servicio	Función
 # Polly	    Texto → Voz
 # Transcribe	Voz → Texto

* Una empreas necesita que su aplicación lea automáticamente noticias escritas en voz natural
 # Amazon Polly

 *Polly = texto que habla*
