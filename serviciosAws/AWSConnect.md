* Que es ?
#  Amazon connect es un servicio de contact center en la nube que permite crear call centers para atender llamadas, chats y contactos de clientes
# es un callcenter como servicio de AWS

* Para que sirve
# sirve para 
 - atencion telefonica a clientes
 - call centers entrantes y salientes
 - Soporte tecnico
 - Ventas
 - Soporte omnicanal ( voz, chat)
# sin infraestructura propia todo gestionado por AWS 

* como funciona
# los clientes llaman a un número
# Amazon connect
 - recibe la llamada
 - ejecuta flujos de contacto
 - enruta al agente correcto
# los agentes atienden desde un navegador web

* pregunta examen
# una empresa quiere implementar un callcenter con agentes humanos, pero desea usar bots para atender preguntas simples antes de transferir la llamada
 * amazon connect
