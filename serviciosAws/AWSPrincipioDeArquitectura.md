
*  AWS tiene 6 pilares claves 
 # Exelencia operacional
  - Realizar operaciones como codigo
  - Hacer cambios pequeños, frecuentes y reversibles
  - Mejorar continuamente
  - ANticipar fallos
  - Automatizar tareas repetitivas
 # Seguridad
  - Implementar identidad fuerte (IAM)
  - Aplicar el principio de menor privilegio
  - Habilitar trazabilidad (LOGS)
  - Proteger datos en tránsito y en reposo
  - Automatizar respuestas a incidentes
 # Confiabilidad (Reliability)
  - Recuperarse automáticamente ante fallos
  - Probar procedimientos de recuperación
  - Escalar horizontalmente
  - Evitar depender de un solo punto de falla
  - Diseñar para el cambio
 # Eficiencia del Rendimiento
  - Seleccionar recursos adecuados
  - Usar arquitecturas desacopladas
  - Probar rendimiento
  - Adaptarse dinámicamente a la demanda
 # Optimizacion de costos
  - Medir el uso
  - Eliminar recursos innecesarios
  - Usar modelos de pago por consumo
  - Elegir el tipo de recurso correcto
  - Analizar gastos regularmente
 # Sostenibilidad (Sustainability)
  - Usar recursos eficientes
  - Optimizar utilizacion
  - Reducir hardware innecesario
  - Automatizar apagado de recursos ociosos
