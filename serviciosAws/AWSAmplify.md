* Que es?
 # Un conjunto de herramientas y servicios para desarrollar y desplegar aplicaciones web y móviles 
 # Facilita conectar frontend con servicios AWS
 # Enfocado en desarrolladores
 # Es como un acelerador para construir apps full-stack en AWS

* Para qué sirve? 
 # Para: 
  - Crear aplicaciones web (React, Angular, Vue) 
  - Crear aplicaciones móviles
  - Conectar fácilmente con backend AWS
  - Agregar autenticación
  - Hosting automático con CI/CD

* Ejemplos reales
 # App web con login usando Cognito
 # App móvil que guarda datos en DynamoDB
 # Web estártica desplegada automáticamente desde GitHub
 # Backend serverless API Gateway + Lambda  

* Como funciona ? 
 # Amplify tiene 3 partes principales
 # Librerias para frontend
 # Conectan fácilmente con:
  - Cognito
  - API ateway
  - S3 
  - DynamoDB
 # Amplify Hosting
  - Hosting para apps web
  - CI/CD automático
  - Se conecta con GitHub, GitLab,etc.

 # Amplify Studio
  - Interfaz visual para configurar Backend
  - Crear modelos de datos
  - Configurar autenticación sin mucho código

 # Características importantes
  - Serverless
  - Integracion nativa con servicios AWS
  - CI/CD incluido
  - Fácil integración con
   # Amazon Cognito
   # AWS AppSync
   # Amazon S3
   # AWS Lambda
* Diferencia con otros servicios
 # Amplify → Desarollo y hosting full-stack simplificado
 # Elastic BeanStalk → Deploy de aplicaciones backend
 # AppSync → API GraphQL
 # Cognito → Solo autenticación
